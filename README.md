# NOVA-3 — Interactive Terminal Lab Companion

An interactive, zero-dependency terminal-based lab companion built for **VTU 2025 Scheme CSE** students. Designed to help practice core lab concepts directly from the command line on any device.

## Features
- **Git Sandbox:** Learn and practice essential Git commands safely.
- **DSA in C:** Block-by-block code breakdowns and memory visualizations.
- **Java OOP:** Interactive object-oriented programming concepts and debugging drills.
- **Viva Preparation:** 90+ curated viva questions with clear explanations.

## How to Run
1. Clone this repository:
   git clone https://github.com/MdNouman36/NOVA-3.git
   cd NOVA-3
2. Run the application:
   python3 play.py
